# 🌍 Internet Ki Starting

1990s ke time Internet naya-naya popular ho raha tha.

Us time websites bahut hi simple hoti thi.

Website me sirf ye cheeze hoti thi:

* Text
* Images
* Links

Example:

```
Welcome to My Website

Home
About
Contact
```

Agar user button click kare...

Ya form submit kare...

Ya calculator chalana ho...

Ya validation karni ho...

To browser kuch bhi nahi kar sakta tha.

Har chhoti request server ke paas jaati thi.

Example:

```
User Name Fill Kiya
↓

Submit
↓

Request Server Gayi
↓

Server Check Karega
↓

Response Aayega
↓

Page Reload
```

Har baar page reload hota tha.

Internet slow tha.

Dial-up connection hota tha.

Ek page load hone me bhi bahut time lagta tha.

Isliye developers ko ek language chahiye thi jo browser ke andar hi chale.

# 🌐 Netscape

![Architecture](https://dummyimage.com/1000x250/0f172a/ffffff\&text=Netscape+Navigator)

## Netscape Kya Tha?

Netscape Navigator us time ka sabse famous web browser tha.

Aaj ke Chrome jaisa.

1994-95 ke aas paas almost sab log Netscape hi use karte the.

Us time market kuch aisa tha:

```
Browser Market

Netscape --------------- 80%+

Others ------------------ Remaining
```

Netscape ka target tha:

> Browser ko smart banana.

Sirf webpage dikhana nahi.

Interactive banana.

---

## Netscape Ki Problem

Browser ke andar koi programming language hi nahi thi.

Sirf HTML aur CSS.

Example:

```
Button Click Hua

↓

Kuch bhi nahi hua
```

Ya

```
Age Enter Karo

↓

Server Check Karega

↓

Page Reload
```

Bahut slow process.

Netscape ne decide kiya:

"Hume browser ke andar ek scripting language chahiye."

# ☕ Java

Ab yaha bahut log confuse ho jate hain.

Java aur JavaScript same nahi hain.

Bilkul alag.

Us time Java bahut popular language thi.

Java ka slogan tha:

> Write Once, Run Anywhere.

Large applications ke liye use hoti thi.

Sabko lagta tha future Java ka hai.

## Java vs JavaScript

| Java               | JavaScript                    |
| ------------------ | ----------------------------- |
| Compiled           | Interpreted / JIT             |
| OOP Focus          | Multi-paradigm                |
| JVM Par Chalta Hai | Browser Engine Par Chalta Hai |
| Large Apps         | Web Interaction               |
| Strongly Typed     | Dynamically Typed             |

Inka sirf naam similar hai.

# 📜 LiveScript

JavaScript ka original naam JavaScript nahi tha.

Sabse pehle iska naam tha:

```
LiveScript
```

Reason:

Ye browser ke andar "live" run hoti thi.

HTML ko dynamic banati thi.

Example:

```
Button Click

↓

Color Change

↓

Popup

↓

Validation

↓

Animation
```

Ye sab LiveScript kar sakti thi.

# 😵 Browser Compatibility Issues

Yahi JavaScript history ka sabse bada problem tha.

Netscape ka JavaScript alag.

Internet Explorer ka JScript alag.

Example:

Code Netscape me chal raha hai.

Lekin Internet Explorer me error.

Ya

Internet Explorer me chal raha hai.

Firefox me nahi.

Developers ko ek hi kaam ke liye alag code likhna padta tha.

Example:

```
if (Netscape)
{
   Code A
}

if (Internet Explorer)
{
   Code B
}
```

Imagine karo...

Ek hi website.

Do browser.

Do alag implementation.

Kitni problem hogi.

# 🎯 Interview Questions

### Q1. JavaScript kisne banayi?

**Answer:** Brendan Eich.

### Q2. JavaScript kitne din me bani?

**Answer:** First version lagbhag 10 din me develop hua.

### Q3. JavaScript ka pehla naam kya tha?

**Answer:** LiveScript.

### Q4. JavaScript ka naam JavaScript kyu pada?

**Answer:** Java us time bahut popular thi. Marketing purpose se LiveScript ka naam JavaScript rakh diya gaya.

### Q5. Java aur JavaScript same hain?

**Answer:** Nahi, dono alag programming languages hain.

### Q6. Browser Wars kin ke beech hui?

**Answer:** Netscape Navigator aur Microsoft Internet Explorer ke beech.

### Q7. JScript kya thi?

**Answer:** Microsoft ka JavaScript implementation jo Internet Explorer ke liye banaya gaya tha.

### Q8. Browser Compatibility Issues kya hoti hain?

**Answer:** Jab ek browser me code sahi chale aur dusre browser me alag behavior ya error de, use Browser Compatibility Issue kehte hain.
